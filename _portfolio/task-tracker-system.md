**Tech stack:** ASP.NET Core, ReactJS, Redis, MSSQL Server, GitHub Actions, Docker (2025)

A full-stack application that lets software engineers track their regular tasks. Built using Clean Architecture, CQRS, and the Repository Pattern, with Redis caching to reduce database load by 40% and response times by 50%.

* Ranked **1st on the .NET Leaderboard** at Learnathon 3.0 (Brain Station 23) with a 98/100 SonarCloud quality score.
* Automated CI/CD with GitHub Actions, cutting deployment time from 30 minutes to 5 minutes.
* Containerized services with Docker for consistent deployments.
